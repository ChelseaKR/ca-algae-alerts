# ios/

SwiftUI, iOS 17+, iPhone only for 1.0, no third-party dependencies. The
project is generated by XcodeGen from `project.yml` (`xcodegen generate`);
both are committed.

- `AlgaeCore/`: a Swift package with the models, the strict snapshot
  decoder, `StatusWording` (the same sentences as the website's
  `wording.py`), the alert planner, stores, the network refresher, search
  and the widget digest. `swift test` on a Mac, no simulator.
- `AlgaeAlerts/`: the app (browse and search, lake screens with history,
  favorites, alerts, purchase, introduction, About).
- `AlgaeAlertsWidgets/`: the "Favorite lakes" widget, part of full access.
  It reads a small digest the app writes to the App Group container and
  makes no network request.
- `AlgaeAlertsTests/` (hosted unit tests) and `AlgaeAlertsUITests/` (the
  real app on a simulator: introduction, search, a lake, favoriting, an
  accessibility audit, a check that no screen says a water is safe, and the
  screenshot capture).

## Run the tests

```sh
cd ios/AlgaeCore && swift test
cd ios && xcodebuild test -project AlgaeAlerts.xcodeproj -scheme AlgaeAlerts \
  -destination 'id=<simulator udid>' CODE_SIGN_IDENTITY=-
```

Use an `id=` destination, not a name: several simulators share names on a
busy machine. `-uiTesting` (set by the UI tests) keeps every file in a fresh
temporary folder and skips the network.

## Data

`AlgaeAlerts/Resources/snapshot.json` is the snapshot that ships in the app,
rebuilt from `pipeline/data/history.json` by `scripts/sync-bundled-snapshot.sh`
with no network. The app shows the newer of that and the last one it
downloaded. Its one network request is a conditional GET of
`https://lakenotice.com/snapshot/v1.json`, which does not serve until the site
is published (docs/DECISIONS.md 0013, docs/DOMAIN.md). Until then a
check fails, the app says "The last check for newer data did not finish",
and keeps showing the bundled data with its date.

## Purchase

`AlgaeAlerts/App/PurchaseManager.swift` is StoreKit 2 (adapted from Trout
Truck's). `AlgaeAlerts/Configuration.storekit` carries the product for local
testing; the scheme points Run and Test at it.
